
# alarm-basah
proyek IoT membuat alarm yg bisa menyemprot air #miau :flushed:

note: alat semprotnya adu nasib bjir, kalo gk kena air bisa rusak

## # material
- Arduino Nano V3 CH340 Atmega 328P
- Nano Expansion Shield Extension
- LCD 16x2 I2C Module 
- Keypad Matrix 1x4 
- Relay 1 Channel 
- Modul Atomizer Humidifier Mist Maker

## # rangkaian kabel
- GND = hitam
- VCC = merah
- Digital/Analog = biru
- SDA/SCL = putih
